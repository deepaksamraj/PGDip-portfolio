## 🌟 Highlights

- **Firewall Monitoring Tool (Python Project1)**  
  Automated firewall log parsing with CSV reporting and unit tests, improving visibility and security.  

- **LAN Infrastructure Project (Networking)**  
  Designed scalable VLAN architecture, wirelist analysis, and firewall perimeter design compliant with ISO 11801.  

- **Server Infrastructure Deployment (Hybrid Cloud Technology)**  
  Delivered VMware cluster setup, rack planning, and AD/DNS/DHCP services with BCDR strategy.  

- **Ansible Automation Coursework**  
  Developed playbooks for Apache/MariaDB deployment and system updates, with host inventory management.  

- **Linux Scripting Module**  
  Built 17 shell scripts covering process management, loops, CLI arguments, and system checks.
